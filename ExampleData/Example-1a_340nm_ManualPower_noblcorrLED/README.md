# 340 nm raw-LED example

`analysis.json` selects the direct absorbance (`emission`) fit, the Crespi Lab
AHK timestamps, Spectragryph spectra, and the generic CSV reader for the LED.

The historical TXT and figure outputs are retained as archival records. 
They are now put in LegacyResults. They were produced at different stages
of the legacy implementation and are not used as exact numerical regression 
targets. The current core configuration is the reproducible definition 
of the calculation.
