# 340 nm raw-LED example

`generic_inputs/analysis.json` uses only plain, headered CSV files.
`crespi_group_inputs/analysis.json` runs the same direct-absorbance (`emission`)
fit from the original Crespi group AHK, SpectraGryph, and LED files.

The historical TXT and figure outputs are retained as archival records. 
They are now put in LegacyResults. They were produced at different stages
of the legacy implementation and are not used as exact numerical regression 
targets. The two current core configurations are reproducible definitions
of the calculation.
