# 455 nm concentration example

`generic_inputs/analysis.json` uses plain, headered CSV files.
`crespi_group_inputs/analysis.json` uses the original SpectraGryph and Crespi
group AHK inputs. Both select `concentrations`, the legacy pure-NNLS method,
and produce equivalent results.

The historical TXT and figure outputs are retained as archival records. 
They are now put in LegacyResults. The current core result is covered by 
the automated concentration method.
